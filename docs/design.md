# Dashboard palette

The current dashboard uses the shared warm brown palette in both themes. Layout, system typography, evidence disclosures and semantic status colors are preserved.

| Role | Light | Dark |
| --- | --- | --- |
| Page | `#F7F3EB` | `#30251F` |
| Panel | `#FFFDF8` | `#403128` |
| Text | `#30251F` | `#F7F3EB` |
| Muted text | `#6B5749` | `#D3C0AD` |
| Border | `#9A8370` | `#9A8370` |
| Filled action | `#8F3D3D` with `#F7F3EB` text | Same |

The sidebar stays `#30251F` with ivory text and `#D3C0AD` secondary text in both themes. Its hover surface is `#403128`. Focus outlines use the local foreground so they contrast with the page and sidebar. The tan border is slightly darker than the initial `#A18B78` proposal to exceed 3:1 against the ivory page. Error, warning and success retain distinct colors, icons and words. Normal text meets 4.5:1; control borders and focus outlines meet 3:1.

PR notes and older changelog fragments describe historical designs, rather than current palette guidance.
